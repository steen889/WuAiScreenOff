## 这是什么

一个极小的 Windows 熄屏小工具(单文件、绿色、离线)。和系统"锁屏"不同——它**只把屏幕熄掉、不锁电脑**:后台的下载 / 渲染 / 远程 / 挂机任务一秒不停,你唤醒后**直接回到桌面,不需要重新输入开机密码**。界面跟随系统语言自动中 / 英切换。


## 三个版本

| 文件 | 说明 |
|---|---|
| `吾爱熄屏.exe` | **纯熄屏** —— 动一下键鼠就亮,最省事 |
| `吾爱熄屏口令版.exe` | **口令亮屏** —— 只有盲打对口令才亮,乱碰不亮(防误触) |
| `吾爱熄屏融合版.exe` | **双模式** —— 双击后自己选「熄屏」或「口令」 |

> 三个版本由**同一份源码** `吾爱熄屏.cs` 用 `/define` 编出,按需取用。

> **🔑 用「口令版 / 融合版」前,先记牢这三条:**
> - **不分大小写**;输错不亮。
> - **忘了口令** → 长按 **Esc 3 秒**强制亮屏。
> - **把 exe 挪到新目录 / 改名** → 自动清除旧口令、要求重设(免得旧口令把你锁在外面)。

## 什么时候用

后台挂着**下载 / 视频渲染 / 远程桌面 / 游戏挂机**等长期任务,人临时离开:熄屏省电、护眼、防人瞄屏,任务照跑不断,回来一唤醒即亮。

**「口令」模式效果像锁屏、却不真锁屏** —— 盲打你设的口令才点亮,挡得住猫爪、误碰、好奇的同事,又省去每次重输开机密码的麻烦。

## 口令(口令版 / 融合版)

- 字母 / 数字,可以只设 **1 位**,也可以是复杂组合
- **不分大小写**,输错不亮
- 万一忘了:长按 **Esc 3 秒**强制亮屏
- 挪了目录 / 改了文件名会自动要求重设(防止换机器后口令失效)
- 口令只存注册表一条,exe 所在目录**不留任何文件**

## 笔记本 / 台式(自动适配)

| 设备 | 熄屏方式 | 说明 |
|---|---|---|
| **笔记本**(能调背光) | 背光调最低 + 盖黑窗 | 避开部分老核显"DPMS 关屏后黑屏点不亮"的坑,代价是屏幕留一点微光 |
| **台式 / 外接屏**(调不了背光) | DPMS 真关显示器 | 真正断显示信号、真省电(等同系统"超时自动关屏"),动键鼠即亮 |

程序启动时自动判断,无需手动设置。

## 亮度保险

熄屏会把笔记本背光压到最低,正常唤醒退出时自动还原。万一程序**被强制结束 / 崩溃**(没走到还原那一步),它会把原始亮度记在注册表里,**下次启动自动还原**——屏幕不会暗着回不来。

## 下载使用

到 [**Releases**](../../releases) 下载,下载名为英文,对应关系:

| Releases 下载名 | 版本 |
|---|---|
| `WuAiScreenOff.exe` | 纯熄屏 |
| `WuAiScreenOff-Password.exe` | 口令版 |
| `WuAiScreenOff-Combo.exe` | 融合版 |

1. 下载需要的版本,双击运行(即时熄屏 / 弹出选择界面)
2. 唤醒方式见上方"三个版本"

> 单文件、免安装、不写系统目录。不想用了直接删 exe 即可(口令 / 亮度记录在注册表 `HKCU\Software\WuAiScreenOff*`,介意可一并删除)。

## 常见问题

**Q:杀毒软件报毒?**
口令版 / 融合版用了底层键盘钩子(熄屏时拦住 Win 键、防止弹出开始菜单泄露桌面),这个 API 和"键盘记录器"同款,个别杀软会**误报**。源码完全开放,可自行审阅、自行编译。纯熄屏版不含钩子。

**Q:会联网 / 上传数据吗?**
不会。全程离线,无任何网络行为。

**Q:在注册表写了什么?**
最多两处:`WuAiScreenOff_Password`(你的口令)和 `WuAiScreenOff`(亮度保险)。卸载删键即清。

**Q:关屏后点不亮?**
那是个别显示器 / 核显的 DPMS 兼容问题。笔记本默认用更安全的"盖黑窗"模式规避。

## 兼容性 & 自行适配

Windows 设备的显卡 / 驱动 / 显示器 / 电源策略千差万别,熄屏、唤醒、亮度还原这类底层行为在不同配置上**可能表现不一致**——比如某些核显的 DPMS 唤醒、外接屏 / 多屏差异、特定电源策略下的亮度行为等,都可能引发个别兼容问题。这类问题往往和具体硬件强相关,很难有一套设置通吃所有机器。

好在源码**只有一份 `吾爱熄屏.cs`、精简易读**。如果在你的机器上遇到不适配,完全可以对照源码、按自己的配置改一改再自行编译——常见可调点:

- **熄屏策略**:盖黑窗 vs DPMS 真关(看 `useDPMS` 的判断)
- **亮度逻辑**:WMI 背光最低值、还原时机
- **多屏 / 唤醒**:盖黑窗覆盖范围、唤醒触发条件

改动都集中在这一个文件,改完双击 `编译.bat` 重新生成即可。
